Replica - Promo Page

Link to website (desktop only)


"REPLICA" is a mock promotional landing page made as part of a web tech college solo assignment.


The brief for the assignment required me to choose a piece of media and make a promo page for it. I chose to do it for the launch of the album "Replica" by Oneohtrix Point Never. The minimum requirements for the page were to keep it on one page and include 8 sections, 6 of which should fill the screen and 2 of which can be more experimental.


As this was a solo project, I was responsible for creating all elements of the site. This included the planning, the visual design, the user experience, the interactive elements and the coding, which was done using HTML, CSS and Javascript.

Tools

  • Illustrator - design and planning
  • Photoshop - image creation and editing
  • HTML and CSS - content and layout
  • Javascript - interactive elements

Skills

  • Graphic Design - typography, image choice and layout
  • UX Design - interactions and navigation
  • Problem Solving - Javascript code issues
  • Coding - HTML, CSS and Javascript


One of the parts I am most proud of is how the design, layout and interactions capture and promote this "clients" unique style and appeal. I made sure that it acccurately represents what the client is about, but with enough stylistic flair and interaction to keep the visitor interested and engaged. I also think the tracklist section and the interactions with hovering and having music videos play really stands out.


During the creation of this site, I learnt alot about general proficiency in web coding, especially Javascript as I didn’t have much practical experience in that before this project. Going into this project, I was very confident in my idea, both the visual and interactive elements, but if I was to do anything differently, I would have expanded on the process book and tracked the progress I made in more detail.


This site also won the Student Media Award for "Best Interactive Digital Experience" in 2026.
