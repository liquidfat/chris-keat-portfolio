Reallife.com - Interactive website

Link to website (desktop only)


"Reallife.com" is an interactive narrative website that was made as part of a college solo assignment.


The brief for the assignment was to create a website with real narrative content and interaction that changes how the user explores and understands information. You could create whatever type of narrative you wanted, but the emphasis was on interaction.


I chose to make a mystery/adventure game inspired by classic point and click games, with ARG (Alternate Reality Game) elements, in the style of an 90's selfmade blog/site.


This was a solo project so I was responsible for all elements of the creation. This included visual design, interaction design, user experience, storytelling and coding.

Tools

  • Illustrator - design and layout planning
  • Photoshop - asset creation and editing
  • HTML and CSS - content and layout
  • Javascript - interactive elements

Skills

  • Graphic Design - image editing, web design and layout
  • UX Design - navigation and interaction
  • Interaction Design - puzzle solving
  • Problem Solving - guiding the user and challenge level
  • Storytelling - writing and visual storytelling
  • Coding - Javascript elements


For me, the most succesful element of this project is the use of nonlinear storytelling and interaction. I designed it so the user would have to jump back and forth between pages to piece puzzles together and progress, which I think keeps the experience engaging and interesting.


One of the most important things I learnt from this project was how to design interactions and guide the user through the experience, while keeping it engaging and not boring (especially since this is a mystery game/experience which requires a certain level of difficulty and intrigue to keep it engaging).
